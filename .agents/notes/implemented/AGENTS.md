# AGENTS.md — implemented 笔记的维护边界

本目录的 Agent Note 描述**已上线**的决策。遵循[根指令](../../../AGENTS.md)与 [Agent Note 格式](../README.md)；`npm run verify:notes` 校验生命周期特定的结构。

## 与线上实际保持同步

路径、符号、默认值与机制的事实，必须在**同一变更**中更新。原地改写过期事实，不追加变更历史。
当已上线的笔记不太可能指导未来工作时，按[归档机制](../README.md#归档机制)归档，而不是继续维护它。

### 这不是重写*决策*的许可

原地更新的是事实实现。决策或理由的反转必须写新 Agent Note 并交叉链接；被完全替代的旧笔记只能按 [Agent Note 规则](../README.md) 的合并规则删除。
